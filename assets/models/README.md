The embedded `haarcascade_frontalface_default.xml` is the frontal-face Haar
cascade distributed with OpenCV 4.10.0, created by Rainer Lienhart.

Source: <https://github.com/opencv/opencv/blob/4.10.0/data/haarcascades/haarcascade_frontalface_default.xml>

The XML includes the original Intel Open Source Computer Vision Library
license. Preserve that notice when redistributing this model, including in
binary distributions. No model download or network access is needed at runtime.
